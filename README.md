# CRUD-form-js-v1
Un projecte bàsic per practicar REST api, docker i backend (expressjs).

** Només volem enviar dades. **
Encara no feim validació de dades.

Obejectius:
- Enviar dades al backend (formulari)
- Deploy del front i back amb docker.
- Emmagatzemar dades amb sqlite de nodejs

Tecnologies usades:
- HTML, CSS , JS vanilla -> Frontend
- Docker -> Deploy al web server i segmenetar
- Nodejs (expressjs i sqlite) -> backend
